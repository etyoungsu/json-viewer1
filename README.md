## JSON Studio
### browser-based JSON/JSONL formatter
- Automatically detects and formats JSON/JSONL.
- Supports collapsible trees, navigation, and search.
- Supports file upload, copy, and download.
- Includes a Vim-inspired dark mode with a light theme toggle.
- Wraps long lines in Input and Output without changing the data.
- Processes data locally without server uploads.
- Supports files up to 10 MiB and 200 nesting levels.
